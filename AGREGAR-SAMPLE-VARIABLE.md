# 📝 Agregar Sample a Variable - Guía

## 🔍 ¿Qué es un "Sample"?

**Sample (Ejemplo):**
- Es un **ejemplo de contenido** que enviarás en la variable `{{1}}`
- **WhatsApp lo requiere** para aprobar el template
- Te permite mostrar qué tipo de mensaje enviarás

**Importante:**
- ⚠️ **DEBES** agregar un sample para poder enviar el template para aprobación
- ⚠️ Si no agregas el sample ahora, **NO podrás enviarlo después**
- ⚠️ **NO selecciones** "Save without samples" (no podrás aprobar después)

---

## 📋 Paso 1: Agregar el Sample

### En el campo "Enter Sample data":

**Escribe un ejemplo** de qué mensaje enviarás. Algunas opciones:

**Opción 1 (Simple):**
```
Recordar pagar la luz mañana a las 5pm
```

**Opción 2 (Más descriptivo):**
```
Tienes una cita médica el 20 de enero a las 10:00 AM
```

**Opción 3 (Ejemplo realista):**
```
No olvides pagar la factura de internet antes del 25 de enero
```

**Recomendación:**
- ✅ Usa un ejemplo **realista** de lo que enviarás
- ✅ Muestra el **formato** típico de tus recordatorios
- ✅ Usa **español** (ya que el template está en español)

**Ejemplo recomendado:**
```
Recordar pagar la luz mañana a las 5pm
```

---

## 📋 Paso 2: Guardar el Sample

### Después de escribir el sample:

1. **Revisa** que el sample sea claro y representativo
2. **Haz clic en**: **"Save"** (dentro del modal)
3. **El sample se guardará** para la variable `{{1}}`

---

## 📋 Paso 3: Enviar para Aprobación

### Después de guardar el sample:

1. **Aparecerá** el botón **"Save and submit"** (ahora habilitado)
2. **Haz clic en**: **"Save and submit"**
3. **El template se enviará** para aprobación de WhatsApp

---

## ⚠️ NO Selecciones "Save without samples"

### Por qué NO debes seleccionarlo:

- ❌ **NO podrás** enviar el template para aprobación después
- ❌ **WhatsApp requiere** el sample para aprobar
- ❌ Tendrás que **editar el template** y agregar el sample después
- ❌ Es más complicado hacerlo después

**Siempre agrega el sample ahora.**

---

## 📋 Proceso Completo

### Paso a paso:

1. **En el campo "Enter Sample data"**, escribe:
   ```
   Recordar pagar la luz mañana a las 5pm
   ```
   (O cualquier ejemplo que prefieras)

2. **Haz clic en**: **"Save"** (dentro del modal)

3. **El modal se cerrará** y volverás a la página del template

4. **Haz clic en**: **"Save and submit"** (ahora habilitado)

5. **El template se enviará** para aprobación

---
