# 🔍 Encontrar el Campo para Agregar Sample - Guía

## 🔍 Dónde Está el Campo

**El campo "Enter Sample data" debería estar visible en el modal.** Si no lo ves, intenta lo siguiente:

---

## 📋 Opción 1: Buscar en el Modal

### El modal debería mostrar:

1. **Título**: "Add sample to variable"
2. **Texto explicativo**: Sobre por qué necesitas el sample
3. **Body**: "Body: Recordatorio: {{1}}"
4. **Sample for**: "{{1}}"
5. **Campo de texto**: "Enter Sample data" ← **Este es el campo que necesitas**

**Si no ves el campo:**
- ⚠️ Puede estar **debajo** del texto explicativo
- ⚠️ Puede necesitar **hacer scroll** en el modal
- ⚠️ Puede estar **oculto** o necesitar hacer clic en algo

---

## 📋 Opción 2: Hacer Scroll en el Modal

### Proceso:

1. **Haz scroll hacia abajo** dentro del modal
2. **Busca** el campo "Enter Sample data"
3. **Debería estar** después del texto "Sample for: {{1}}"

---

## 📋 Opción 3: Cerrar y Reabrir el Modal

### Si el campo no aparece:

1. **Haz clic en**: **"Cancel"** o **"Close modal"**
2. **Vuelve a hacer clic** en el botón que abre el modal (puede ser "Add sample" o similar)
3. **El modal debería abrirse** con el campo visible

---

## 📋 Opción 4: Buscar en la Página Principal

### Si el modal no funciona:

1. **Cierra el modal** (haz clic en "Cancel" o "Close modal")
2. **En la página principal**, busca:
   - Un botón que diga **"Add sample"** o **"Add Variable Sample"**
   - O una sección que diga **"Variable Samples"**
3. **Haz clic** en ese botón o sección
4. **Debería aparecer** el campo para agregar el sample

---

## 📋 Opción 5: Agregar Sample Directamente en el Body

### Si no encuentras el campo separado:

1. **En la sección "Body"**, busca si hay una opción para agregar samples
2. **Puede haber** un botón o enlace que diga "Add sample" o "Edit sample"
3. **Haz clic** en ese botón
4. **Debería aparecer** el campo para agregar el sample

---

## 📋 Opción 6: Usar "Save without samples" Temporalmente

### Si realmente no encuentras el campo:

1. **Haz clic en**: **"Save without samples"** (solo temporalmente)
2. **Guarda** el template
3. **Luego**, busca en la página del template una opción para **"Edit samples"** o **"Add samples"**
4. **Agrega** el sample desde ahí

**Nota:** Esto es menos ideal, pero puede funcionar si no encuentras el campo en el modal.

---

## 🔍 Qué Buscar Específicamente

### El campo debería verse así:

```
Sample for: {{1}}
[Enter Sample data]  ← Campo de texto aquí
```

O puede verse como:

```
Sample for: {{1}}
┌─────────────────────────────────────┐
│ Enter Sample data                    │  ← Campo de texto
│                                       │
└─────────────────────────────────────┘
```

---

## ⚠️ Si Realmente No Aparece

### Puede ser un problema técnico:

1. **Intenta refrescar** la página (F5 o Ctrl+R)
2. **Intenta cerrar** y volver a abrir el navegador
3. **Intenta usar** otro navegador
4. **Intenta hacer clic** en diferentes partes del modal

---

## 📋 Proceso Alternativo

### Si no encuentras el campo en el modal:

1. **Haz clic en**: **"Cancel"** o **"Close modal"**
2. **Guarda** el template sin el sample (usa "Save" normal)
3. **Luego**, en la página del template, busca:
   - Una sección de **"Variables"** o **"Samples"**
   - Un botón que diga **"Edit samples"** o **"Add samples"**
4. **Agrega** el sample desde ahí
5. **Luego** envía para aprobación

---

## ✅ Resumen

**Qué hacer:**
1. ✅ **Haz scroll** en el modal para buscar el campo
2. ✅ **Busca** el texto "Enter Sample data"
3. ✅ **Cierra y reabre** el modal si no aparece
4. ✅ **Busca** en la página principal si hay un botón para agregar samples
5. ✅ **Si nada funciona**, guarda sin samples y agrega después
